# Awais Malik — Portfolio

Personal portfolio built with React, TypeScript, and Vite.

## Local development

```bash
pnpm install
pnpm dev
```

Open [http://localhost:8443](http://localhost:8443).

## Production build

```bash
pnpm build
```

The deployable site is generated in `dist/`.

## Publish with GitHub Pages

1. Create an empty GitHub repository.
2. Push this project to its `main` branch.
3. In the repository, open **Settings → Pages**.
4. Set **Source** to **GitHub Actions**.
5. Open the **Actions** tab and wait for “Deploy to GitHub Pages” to finish.

Every later push to `main` automatically republishes the site.
